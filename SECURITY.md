
# Security Policy

## Reporting a Vulnerability

The security of PocketMC and its users is important.

If you discover a security vulnerability, please report it privately rather than publishing the details in a public issue.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the maintainer through an appropriate private channel listed on the official GitHub profile or repository.

When reporting a vulnerability, please include:

- A clear description of the issue.
- The steps required to reproduce it.
- The potential impact.
- Relevant logs, screenshots, or proof of concept, if available.
- Any suggested mitigation, if known.

Please avoid including passwords, access tokens, private keys, personal information, or other sensitive data in your report.

## Disclosure

Please allow the maintainer reasonable time to investigate and address a reported vulnerability before publicly disclosing technical details.

Submitting a report does not guarantee a response, a fix, or a specific resolution timeframe. PocketMC is a hobby project maintained at the maintainer's own pace.

The maintainer may request additional information to verify the report.

## Scope

Security reports should concern PocketMC's own code, build process, distribution, or project infrastructure.

Issues involving third-party libraries or software may need to be reported to their respective maintainers.

Thank you for helping keep PocketMC and its users safe.
